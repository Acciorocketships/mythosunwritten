# Rock selection catalog

308 asset entries in 34 native Godot contact sheets. Newest packs first. Two opposite oblique views, source geometry, imported materials, neutral lighting. Display size is normalized; dimensions are native bounds in metres. No slope deformation or game moss shader.

Open `index.html` for the searchable gallery. `manifest.json` maps all selection IDs to source paths.

Duplicate formats and KayKit palette variants omitted; stone architecture excluded. Meadow seasonal variants retained. Generated project rock libraries explicitly labeled. Rock and slope corrections remain pending owner selection: the rejected prior pass remains the production state; exploratory changes from the correction turn were restored before making this catalog.
