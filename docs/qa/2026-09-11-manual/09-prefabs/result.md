# Prefab integration

All 32 complete native buildings are retained in the source selection pool,
instead of losing 15 when equal reservation profiles are deduplicated. The
planner searches each measured footprint once and selects its actual native
building before modular partitioning. Each tier requests one additional site;
complete bearing, visual/body clearance and a street-facing entrance still
control admission. Native buildings retain their full authored geometry and
floors, and share the existing town ground, platforms and street interfaces.
This does not add shared-wall openings or playable interior connections.

The photographed town retains two prefabs and all 28 modular room records. Its
first native house changes from LPFV house 01 to house 07. In the twelve-compact
source comparison, prefab count increases from 9 to 10: seed 11 admits a second
native house and changes from 27 modular rooms to 18. The extra reservation is
part of the source allocation, not a building overlaid onto finished rooms.
The selected recipe also enters the deterministic source signature, independently
of audit iteration order.

The photo and seed-11 native capsule surveys are exactly equal before/after,
respectively 88 positions / 124 crossings and 76 positions / 108 crossings.
Every sampled centre and crossing is clear. The new tests pass 132 assertions;
the independent canonical-template test passes 207, and all 32 native prefab
floor contracts pass the existing floor tests. The broader source-plot run
reproduces the same 13 failing assertions as an isolated pre-change baseline.
The final scale/prefab run passes 10/11 tests, 246/248 assertions, retaining two
unrelated historical compact crown/skywalk pins. No performance or geometric
acceptance threshold is weakened.

Fifty-two native pairs have been judged: sixteen photo-context pairs, sixteen
seed-11 town views, and twenty close details. Ten details are explicitly
context-only because market awnings or neighboring buildings obscure the
complete target. Paired pixel differences and per-image judgments are in
[the image audit](image-audit.md). Photo-context mean absolute RGB changes are
0–0.652 /255; seed-11 overview changes are 1.832–3.885 /255. Larger local changes
in the detail views correspond to the new native house and its reallocated
modular neighbors. Pixel metrics locate changes; inspection and physical
queries establish whether they are appropriate.

The source overlay rounds coordinates to 0.1 m. Reconstructed before/after
camera transforms match each other exactly; the original full-precision
screenshot camera is not recoverable. The first seed-11 framing attempt was
rejected and archived separately. Native fixtures omit surrounding terrain;
the twelve full in-game photo pairs also pass. Their camera records are exactly
equal. Live whole-frame mean absolute RGB changes span 0.388–1.002 /255, with the
selected prefab and small animated-light/dither residuals accounting for visible
differences. Startup took 274.859 seconds. The final 48-town sweep constructs all 48, retaining 11,112 clear public
positions and 15,923 clear crossings with no disconnected routes. The same
27 off-centre pillar contacts remain; none blocks a route centre or crossing.
The fingerprinted composition gate passes all 95 assertions. Its host
calibration is an invalid 2.810x factor, capped at 2x; the green assertion
result does not establish a reliable performance bound. An isolated paired grand-town stage probe totals 57,197 ms before and
55,976 ms after, with identical 57 plots, 48 parcels, 164 building records and
168 room records. Source plot work increases from 1,050 to 1,304 ms; other stages
vary in both directions. The earlier 185,120 ms corpus outlier is not repeated
in this pair. This is limited evidence against a repeatable total-time regression,
not a performance guarantee or startup improvement. The reported prefab
integration is accepted for source selection, construction and judged visuals.
