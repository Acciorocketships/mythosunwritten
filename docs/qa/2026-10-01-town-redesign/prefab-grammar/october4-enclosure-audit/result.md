# Enclosure after native building integration

Eight representative towns build with zero floating-mass audit findings and zero
public-air roof intrusions. Comparison with the archived October 4 arcade-support
corpus (before native production integration) gives:

| Measure | Archived | Current |
| --- | ---: | ---: |
| Public macro cells | 615 | 617 |
| Covered fine quarters | 334 | 386 |
| Fully covered macro cells | 76 | 90 |
| Supported bridge cells | 17 | 20 |
| Source tunnel cells | 90 | 93 |
| Floating masses | 0 | 0 |
| Roof intrusions | 0 | 0 |

These are aggregate comparisons across intervening changes, not isolated causal
attribution to the native house family. Current cover is only about 15.6% of
public fine quarters. This is not acceptance of the overall enclosed-massif goal.

The enclosure probe now checks actual baked native wall, door and window triangles
for adjacent facade rays. It does not treat conservative private reservation boxes
as occupied walls. A four-orientation regression checks real door faces and empty
private air: one test / 17 assertions pass. No native facades intercept the short
adjacent-cell flank rays in this corpus; native houses must not be credited with
street enclosure merely because they exist somewhere in the town.

## Rejected landing experiment

Allowing a level landing adjacent to a rising stride to nominate a tunnel,
while retaining actual excavation headroom and two solid jambs, added five source
tunnel cells (7/standard +1, 211/grand +4). However, every finished public walk's
coverage remained identical. The change and its experiment-only test were removed.
The five candidates did not become new covered passages. Existing flight exclusion
and horizontal-only bore eligibility remain in production.

`current.json` is the final unchanged production enclosure result;
`rejected-landing-experiment.json` records the rejected candidate. Future enclosure
work needs carving and room allocation to co-decide supported passage covers.
Increasing source tunnel counts alone is not success. No new visual or overall art
acceptance is claimed by this audit.

Final restored production: actual player traverses the covered passage at
7/standard (-1,0,-1) in both directions, 2/2 passing. See
`covered-player-walk.json`. This verifies one retained passage, not all routes.
