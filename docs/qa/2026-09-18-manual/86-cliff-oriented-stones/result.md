# Physical rock variation — pass 86

Production now rotates the eight detached Nature-rock fronts through independent angles instead of shearing consistently upright profiles. The physical depth range increases from 0.7–1.2 to 0.8–1.4 m before existing projection and slope bounds. Relief approaches preserved ledge bearings over 1.25 m rather than 1.6 m, with the search using that complete radius. The actual closed mesh and collision change; there is no texture, shader-normal, material, crack-overlay or native-wall asset change.

The selected `balanced.gd` and production differ only by explanatory comments. `final.gd` is the exact production snapshot. See [production delta](production.patch).
