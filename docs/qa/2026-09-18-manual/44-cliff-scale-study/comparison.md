# Native cliff comparisons — experiments, not selected production

The owner rejected tapered rectangular columns and independent scratch marks. These are actual Godot mesh renders under the same camera/light, not generated concept images. Production is unchanged.

## Three small-detail alternatives

All three use the same underlying shelf construction. `review-clean` removes the added small stone relief entirely. `review-subtle` uses sparse geometric relief and shallow joints. `review-joints` deepens the connected joints on the same partition. They are deliberately comparable, but the shared broad shelf construction still creates upright stretches.

## More continuous upper join

This subsequent study shortens the exposed native-wall gaps and adds broader physical stone variation. It reduces the tiled backing, but still has smooth, slab-like supports in the short-wall replay. It is **not accepted**.

![More continuous upper join](unified-tall/oblique.png)

![Original game camera, ordinary-height wall](unified-context/P12_front.png)

![Adjacent ordinary-height wall](unified-context/P20_oblique.png)

The stronger detail is too visually busy, while removing all small relief exposes the unresolved main forms. Restrained relief is the better detail direction; replacing the larger upright support shapes remains necessary. See [measurements and scope](result.md).
