# Rooted boulder scale experiment — not selected

Prior production stretches each Nature-derived boulder vertically with the backing wall. At the same positions, changing the backing from 32 to 64 m doubles the boulder height. A source-profile invariant reproduces this at 2.0 and fails its 1.2 maximum.

The bounded trial caps these sources by their physical width (height/width 1.25–2.1), retaining the existing embedded feet. The source-scale check passes, as do the existing macro-outline, varied long-ledge and gradual upper-profile checks: four tests / thirteen assertions. Connected upper shelves reach 42.25 m with a 2 m minimum.

Five native 64 m views are retained. The oblique and overhead views still show long support columns. The filtered outline correlation worsens from production 0.527707 to 0.610486, although still below the existing 0.65 limit. The change does not produce the intended improvement and is **not promoted**. Production remains pass 51. Height-stretched Nature profiles contribute, but the persistent shelf support profiles dominate the remaining vertical structure; merely shortening the boulders does not resolve that composition.

No geometry, collision or visual acceptance is inferred from the passing source-scale test. The next cliff investigation should address the full spatial support envelope, rather than repeatedly tuning source dimensions. Other original issues remain open.
